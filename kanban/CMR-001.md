## Description

Beds (Structure kind=Bed) currently exist as structures but the behavior system does not route a sleeping warden to them. When a warden's `rest` need drops below the sleep threshold, the warden should walk to the nearest available, unblocked Bed and only fall back to sleep-in-place if no bed is reachable.

A bed is "available" when no other warden is currently sleeping on it (i.e. occupant == 0 or self).

## Acceptance Criteria

- New helper `findNearestAvailableBed(world, eid)` in `src/game/Sim/systems/behavior.ts` returns the eid of the closest Bed reachable via the path worker, or null.
- When `Needs.rest < SLEEP_THRESHOLD` and a Bed is reachable, the warden walks to it (Path target) and sleeps there; rest restores at the existing rate.
- When no Bed is reachable, the existing sleep-in-place fallback runs and an event is logged once ("<name> sleeps on the ground").
- A Bed is considered occupied while a warden's Position equals the bed's tile; freed when the warden walks off.
- New vitest in `tests/sim/behavior.test.ts` (`it('routes a tired warden to the nearest available bed')`): seed a warden with rest=10 + 2 beds, assert the warden's Path target lands on the closer bed.
- Determinism preserved: tie-breaks must use the shared seeded RNG.
- `npm test`, `npm run typecheck`, `npm run lint` all green.

## Plan Candidates

**What**: Three implementation shapes for routing tired wardens to beds.
**Why**: Choice determines blast radius, save-format risk, and how occupancy is tracked.
**As-Is → To-Be**:
- As-Is: No bed routing; no path hook on behavior system.
- To-Be: One option below chosen for Plan.

- **A — Hook-factory + sync A* probe + TilePos-equality occupancy.** Add `makeBehaviorSystem(hooks)` mirroring jobs/construct; `findNearestAvailableBed(sim, eid)` runs `aStar` once per candidate (≤3 beds in MVP) and returns min-cost reachable bed. Touches behavior.ts, tick.ts, Game.ts, tests. No save migration. Lowest blast radius.
- **B — Add `Structure.occupant: ui32` field.** Behavior writes/clears occupant as wardens enter/leave the bed tile; save codec bumps to v4 with migration. Higher complexity, breaks save compat, fixes a problem (race between query and write) that doesn't yet exist.
- **C — External `sim.bedOccupancy: Map<eid, occupant>`.** Lighter than B (no save migration if we serialize on demand), but adds a second source of truth alongside `TilePos`; risk of desync if a warden teleports (e.g. battle exit). Strictly worse than A for current scope.

## Learnings

**What**: Three durable facts the next ticket can borrow — hook-factory beats schema-bump, FSM edges need explicit path clears, and seeded-RNG tie-break is the only deterministic option.
**Why**: These are the calls that survived a Rewind 1 (HIGH+MEDIUM) and a QA-Failure (fabricated diff) cycle; they were not obvious from the original Plan brief and would burn the next system author too.
**As-Is → To-Be**:
- As-Is: Pattern only existed implicitly in `jobs.ts` / `construct.ts`; no wiki, no precedent doc for sim-tick determinism.
- To-Be: Pattern captured in `docs/llm-wiki/needs-driven-sleep.md` with code anchors and decision log so the next sim-tick feature can copy it.

- Hook-factory (`makeBehaviorSystem(hooks)`) is the cheapest way to add an external dependency (path worker, audio, network) to an ECS system without breaking headless tests — the `NOOP_HOOKS` wrapper keeps the legacy export byte-identical.
- An FSM that gates work on `prev !== next` MUST also clear any cross-system state it overrides on that edge — here, both the active `Job` and `sim.paths` had to be wiped or the bed-walk silently lost to a stale job path (Rewind 1 HIGH).
- Cross-faction Pawns can share a non-blocking tile, so any "is this tile occupied?" query in this codebase needs a `FactionComp.id` filter; the `isMobileOnTile` precedent in `construct.ts` was a near-miss because it did not yet need that filter (Rewind 1 MEDIUM).
- Seeded-RNG tie-break on equal A* path length is the only determinism source that survives save/load — bitecs insertion order looks stable but is not contractually so, and the AC explicitly demands `sim.rng`.
