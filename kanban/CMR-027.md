## Description

Spec mentions traits like "Eager" / "Stubborn" but no system exists. Add 6 traits with deterministic stat modifiers, rolled once at spawn (or tame).

Trait set (illustrative; tune in PR):
- Eager: +10% xp gain
- Stubborn: -1 atk, +2 def, +1 hp
- Nimble: +1 spd, -1 hp
- Hardy: +2 hp, -10% xp gain
- Fiery: +1 atk if type=Ember
- Lazy: -1 spd, +5% bond/tick

## Acceptance Criteria

- New `Trait` enum + `critter.traitId: number` SoA field (default 0 = None).
- `spawnCritter()` rolls trait from shared RNG (table-driven weights).
- `applyTraitMods(critter)` mutates the runtime stat snapshot used by BattleSim.
- UI (SelectionPanel for tamed critter — connects to CMR-021) shows trait name with tooltip describing modifiers.
- Save v3+ additive.

- `npm test`, `npm run typecheck`, `npm run lint` green.
