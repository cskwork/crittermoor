## Description

`Pawn.mood` exists but nothing reads or writes it. Add a tick-paced mood update derived from needs and recent events, and trigger a mental break when mood crosses a low threshold. RimWorld parity (light): one major break type (Berserk) and one minor (Wander).

- mood <- clamp(50 + (food/2 + rest/2 + joy/2 - 75) + recentEventBonus, 0, 100)
- break thresholds: mood <= 15 -> roll for Berserk; mood <= 30 -> roll for Wander; checked every 240 ticks.
- Wander: warden picks a random reachable tile every ~40 ticks for `BREAK_TICKS=720`; ignores jobs; needs still decay.
- Berserk: warden attacks the nearest non-self pawn (any faction) until downed or `BREAK_TICKS` elapse.
- Recovery: when break ends, mood resets to 50, behavior returns to Idle.

## Acceptance Criteria

- New `system_mood` in `src/game/Sim/systems/mood.ts` updates `Pawn.mood` every 60 ticks from needs.
- New `MentalBreak` bitecs component `{ kind: ui8, ticksLeft: ui16 }`; enum `BreakKind { None=0, Wander=1, Berserk=2 }`.
- `system_pawn_behavior` short-circuits to `Behavior.Idle` while `MentalBreak.kind !== None`; movement / combat decisions handled inside the new `system_mental_break`.
- Wander uses `sim.rng` only (deterministic). Berserk picks target via existing path/AStar query.
- Tests in `tests/sim/mood.test.ts`: (a) mood reflects needs; (b) mood <= 15 + seed=42 triggers Berserk within 240 ticks; (c) break ends after BREAK_TICKS and mood resets.
- `npm test`, `npm run typecheck`, `npm run lint` all green.
