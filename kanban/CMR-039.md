## Description

The player has no manual control over wardens. Add RimWorld-style Draft mode:

1. Select one or more wardens (existing selection state, or add a click-marquee in `InputController.tsx`).
2. Press `R` to toggle Drafted on selection.
3. While Drafted: autonomous behavior is suspended. Left-click on a tile = MoveOrder (path request). Left-click on a hostile pawn = AttackMoveOrder (move adjacent then auto-attack).
4. Press `R` again to undraft.

## Acceptance Criteria

- New `Drafted` bitecs component (zero-payload tag) in `components.ts`.
- New `OrderTarget` component `{ tx: i16, ty: i16, attackEid: ui32 }` for the active manual order.
- `system_pawn_behavior` short-circuits when `Drafted` is present: warden ignores Needs-driven transitions and follows `OrderTarget` instead.
- New `system_drafted_orders` consumes the order: path to `(tx,ty)` (or nearest passable neighbor of `attackEid`), auto-attack on arrival if `attackEid !== 0`.
- Keybinding `R` toggles Drafted on the current selection (`src/ui/InputController.tsx`); HUD shows a yellow ring on Drafted pawns.
- Critical needs override draft: `food <= 5 || rest <= 5 || downed` removes Drafted and logs an event.
- Tests in `tests/sim/draft.test.ts`: (a) drafted warden ignores chop designation; (b) drafted warden moves to ordered tile; (c) attack order downs hostile target; (d) critical hunger un-drafts.
- `npm test`, `npm run typecheck`, `npm run lint` all green.
