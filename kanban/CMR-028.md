## Description

Today `raid.ts` schedules raids on a flat timer with a placeholder roster. Add a scaler that derives raid power from colony wealth (sum of structures' build cost + resources + critter levels) and elapsed days. Pick raider critter species + counts from a deterministic roster builder.

## Acceptance Criteria

- New `computeRaidPower(world, day)` returns a target power score.
- New `buildRaidRoster(targetPower, rng)` returns 1..4 critters (species + level) summing to targetPower.
- raid system uses the roster on raid landing.
- Difficulty curve documented in code: power = 50 + day*2.5 + wealth*0.05.
- Test: fixed seed + same state produces same roster; doubling wealth roughly doubles avg roster level.
- `npm test`, `npm run typecheck`, `npm run lint` green.
