## Description

`Needs.joy` decays but nothing restores it and nothing reads it. Add a `JoyObject` structure kind (default: Campfire) plus a `Recreation` behavior state. During the Joy schedule slot (CMR-032) OR when `joy <= 25`, the warden walks to the nearest reachable JoyObject and uses it for `JOY_TICKS=60`, restoring +60 joy.

## Acceptance Criteria

- New `StructureKind.Campfire` in `src/game/Sim/Structures/defs.ts` with `cost:{wood:5}`, `blocksPath:false`, `buildTicks: WORK_TICKS_CHOP * 2`. Placeable from the build menu.
- New `Behavior.Recreation = 4` in `systems/behavior.ts`. Transition: `joy <= 25` OR current schedule slot is Joy -> Recreation; exit when `joy >= 80` OR slot changes.
- Recreation steers the warden to the nearest Campfire via the path worker; on arrival, stand for JOY_TICKS while restoring +1 joy per tick.
- If no reachable JoyObject, fall back to current behavior (no-op) and emit a one-shot event `<name> has nothing to do for fun` (rate-limited to once per 480 ticks per warden).
- Tests in `tests/sim/joy.test.ts`: (a) low-joy warden with a Campfire ends up at the campfire tile and joy rises; (b) no-campfire scenario emits the one-shot event exactly once across 1000 ticks.
- `npm test`, `npm run typecheck`, `npm run lint` all green.
