## Description

Win condition is "launch the airship" (spec) but there is no progression. Add a small 8-node research tree where each node has cost (in research points + wood/stone) and a prerequisite. Research points accumulate from "study" actions (idle warden at a Library structure, or by killing wild critters with intelligence type bias).

Suggested 8 nodes: BasicAgriculture → ImprovedCooking → MetalWorking → BetterTurrets → Hatchery → AirshipChassis → AirshipPropulsion → AirshipFlight (terminal win).
