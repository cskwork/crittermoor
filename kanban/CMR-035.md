## Description

Depends on CMR-034 (items + stockpiles). Add a `Haul` work type so wardens pick up `ItemStack` entities that are NOT inside a Stockpile and walk them to the nearest Stockpile tile that accepts the item kind.

A warden carries one stack at a time. Haul is selected by the priority grid (default priority 3, lower than Chop/Mine/Construct).

## Acceptance Criteria

- New `JobKind.Haul` in `src/game/Sim/systems/jobs.ts`.
- New `Carrying` bitecs component `{ itemEid: ui32 }` - set while a warden is hauling.
- Assignment: idle warden picks the closest reachable `ItemStack` outside any Stockpile, with `WorkPriority[Haul] > 0`.
- States: Seeking -> Moving (to item) -> Pickup (despawn the world ItemStack, set Carrying) -> Moving (to nearest Stockpile tile with empty slot for this kind) -> Drop (spawn ItemStack on destination tile or merge with existing stack, clear Carrying).
- Determinism: tile candidate ties resolved via `sim.rng.int`.
- Tests in `tests/sim/haul.test.ts`: (a) lone wood stack outside stockpile gets hauled in within N ticks; (b) warden with Haul priority=0 ignores it; (c) two wardens never pick the same stack.
- `npm test`, `npm run typecheck`, `npm run lint` all green.
