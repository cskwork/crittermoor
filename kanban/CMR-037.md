## Description

Wardens have `Health.hp / Health.downed` from battle, but no one heals them. Add a `Doctor` work type: an eligible warden walks to a downed/injured patient and restores HP over time.

Eligibility: `WorkPriority[Doctor] > 0` AND `Skills.medicine >= 1`. Target: any friendly pawn with `Health.hp < Health.maxHp` OR `Health.downed === 1`, sorted downed-first then HP%-ascending.

Heal rate: `1 hp per (12 - medicineSkill) ticks`, min 2. When `hp >= maxHp` the patient's `downed` clears and behavior returns to Idle.

## Acceptance Criteria

- New `JobKind.Heal` in `systems/jobs.ts` OR new `systems/medical.ts` (implementer's choice; keep file size <= 250 lines).
- Patients block other work assignment to themselves while downed (they cannot chop while bleeding out).
- Healer needs adjacency (nearest passable neighbor); patient does not move.
- Heal increments `Health.hp`, awards medicine XP capped at 20, emits `<name> tended (+1 hp)` every N heals (to avoid event spam - group emits per 5 hp).
- Tests in `tests/sim/medical.test.ts`: (a) downed warden gets healed to full and stands up; (b) doctor with priority=0 ignores patient; (c) two doctors never both target the same patient simultaneously.
- `npm test`, `npm run typecheck`, `npm run lint` all green.
