## Description

Add a RimWorld-style 24-slot daily schedule per warden. Each slot is one of `Anything | Work | Sleep | Joy`. The behavior FSM gates state transitions on the current slot: during Sleep, the warden seeks bed regardless of rest level (with mild rest tolerance); during Work, jobs run; during Joy, the warden seeks a JoyObject (when CMR-038 lands); Anything = current need-driven behavior.

Default schedule: 22:00-06:00 Sleep, 06:00-21:00 Work, 21:00-22:00 Joy.

Time-of-day is derived from `sim.tick` using a configurable `TICKS_PER_DAY` (default 1440, i.e. 1 tick per in-game minute).

## Acceptance Criteria

- `TICKS_PER_DAY = 1440` constant in `src/game/Sim/systems/time.ts`; new helper `hourOfDay(sim): 0..23`.
- New `Schedule` bitecs component (24 ui8 slots) in `src/game/Sim/components.ts`. Enum `ScheduleSlot { Anything=0, Work=1, Sleep=2, Joy=3 }`.
- Behavior system in `src/game/Sim/systems/behavior.ts` reads the current slot:
  - Sleep slot -> force `Behavior.Sleeping` even if rest > REST_LOW (use a softer threshold `rest < REST_FULL`).
  - Work slot -> skip Sleeping/Eating unless rest <= REST_CRITICAL=10 or food <= FOOD_CRITICAL=15 (critical override).
  - Joy / Anything -> current behavior unchanged.
- Save schema bump (one higher than current head): persist `Schedule` per warden. Legacy saves default to the schedule above.
- Tests in `tests/sim/schedule.test.ts`: (a) warden does NOT chop during Sleep slot; (b) warden DOES sleep during Sleep slot even when rest is comfortable; (c) critical hunger overrides Sleep slot.
- `npm test`, `npm run typecheck`, `npm run lint` all green.
